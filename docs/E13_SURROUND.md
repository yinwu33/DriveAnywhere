# E13：环视补全实验结果

E13 在 val056 完成两轮环视补全和持久 3D 更新。**本次环视场景质量未通过：左右正侧视和后视仍模糊、碎片化，不能作为可测试的完整 3D 场景。** 实验执行完成与质量验收分开记录；完整 Phase 9 仍未完成。

只使用目标场景 FRONT 图像和由其估计的相机、深度与掩码，没有读取真实侧/后相机、Waymo 标定、GT 或 HUGSIM。使用冻结 GEN3C-Cosmos-7B（Cosmos-Predict1）和 MoGe-2，未使用 Cosmos Dream，也未训练生成网络。新内容明确标记为生成内容。

## 方案与目标相机

从 E5c 出发，在原 FRONT 轨迹的 frame 96、104、112 三个估计位置定义虚拟环视相机，八个朝向为 0、±45、±90、±135、180°。每个位置的各朝向共用光心和估计内参，不能解释为已恢复实际车辆的环视相机标定。三位置相邻约 3.85 场景单位、总跨度 7.70；物理米制尺度未验收。

第一轮扫右侧与后方，第二轮扫左侧与后方。每轮三个位置各 37 帧扫视（5°/帧），中间以两段各 5 帧平移连接，一次联合生成 121 帧；不是每个原视频 frame 都生成 N 个视角。模型按原生 121 帧、1280×704、35 步、seed=1 推理；展示帧率 10，对应约 50°/秒的扫视，较快转向是本实验的一项限制，未做速度消融。

每轮固定选 41 个生成目标（索引 0/3/…/120），seed=0 进行 4000 步场景高斯优化；第二轮共同保留第一轮目标，并保存第一轮模型快照。两轮共 242 张生成图和 8000 步 3D 优化。初始化密度、深度对齐及缓存策略也有变化，因此不是与 E11/E12 的单变量角度采样对照。

未知区域掩码依据 FRONT 训练相机里的渲染深度/RGB 支持，而不只依据低 opacity；这里的颜色参考仍是渲染 RGB，并非真实照片，可能让共同错误自我支持（DECISIONS T 已登记）。不透明的无约束碎片也可能落入未知区域，不会因拒收新生成自动删除。

生成器条件来自实际 FRONT 的 RGB-D 投影与历史通过检查的生成 RGB-D；E5c/更新后的 GS 提供相机、参考深度及未知区域掩码。没有将模糊的 GS RGB 直接作为主要生成缓存。真实缓存排除留出帧以及预测动态/天空；模型所需的第一帧仍使用完整真实 FRONT。历史记忆只能补真实 warp 未覆盖处，不能冒充真实观测。

MoGe 深度用已支持的估计场景几何确定统一尺度 1.774385，第二轮固定复用。新区域需通过不同相机中心的深度、遮挡和颜色检查：参考中心分离≥1 场景单位、视差≥0.5°、至少两份独立支持、深度相对误差≤10%、RGB误差≤0.12、冲突比例≤25%。纯旋转不算新增几何证据；未知不作通过。只有验证且被选入训练池的空洞像素可以增补高斯和监督。仍有真实 FRONT loss 锚定；原有无约束不透明高斯不会自动清除，真实区域也不是完全冻结。

最终高斯数 606,447（E5c 初始 676,367；第一轮快照 622,502）。常规 culling 同时可能移除旧/新高斯；没有逐 ID 跟踪，不能由净数量变化推断新高斯的存活率。两轮训练 Torch allocated 峰值 10.60 / 11.00 GiB。

FRONT 历史整图留出 PSNR：E5c 31.391 → 第一轮 32.310 → 最终 32.824 dB；最终 SSIM 0.9370、LPIPS 0.09243。此处只是已使用的上游历史协议；无仅继续真实帧的控制，不能把变化归因于生成，也不替代完整静态区域评测。

通过率是估计 RGB-D 的自洽比例，不是隐藏区域正确率或最终覆盖率。第二轮正左侧在 frame96/104/112 分别通过 1.577/3.918/6.117%，frame96 正后方通过 23.119%；frame104/112 后方仍为 0。第一轮三个正右侧与正后方目标均为 0。第二轮自洽稍多，但直接画面和跨轮布局仍失败。

### 已确认的问题

1. **生成图已经失败。** 原分辨率左右 90° 与后方存在明显模糊、树木/建筑重影和道路结构变化。两轮回看同一位置时，后方道路/庭院布局也明显不同；三位置的相机变化只有 0.00047–0.00118 场景单位、0.018–0.035°，内参相同，但生成条件和轨迹不同，不是完全相同输入的因果对照。因此不能将全部失败归因于 3DGS 蒸馏；更多高斯也不能补救错误的图像目标。
2. **单张深度没有形成统一几何。** 首轮 MoGe 在多个侧视生成图中近似平面，例如 frame96/+90° 深度 p5/median/p95 为 2.17/2.26/2.35 场景单位。估计深度与参考深度比值 p5–p95=0.618–10.959，单个尺度无法处理全部差异。第二轮比值 p5–p95 仍为 0.608–9.494；该轮单独估计尺度为 2.064，主实验按计划保持首轮尺度。参考几何本身也有误差，不能将全部责任归给 MoGe。
3. **有限的验证内容没有充分进入训练。** 首轮全部 121 帧共有 41,517 个通过像素，41 视角的均匀训练网格只包含 3,313 个（7.98%）；大部分 155° 的有效像素未被采到。第一轮只能新增 838 个高斯。实际采样序列显示两轮分别仅 294/4000、566/4000 步选到有通过像素的生成目标（第二轮 82 个联合目标中 11 个有支持）；其余步仍有真实 FRONT 优化，但没有有效生成区域监督。后续应先按可靠覆盖挑选训练目标，而非继续增加均匀角度数。
4. **跨轮记忆确实接入，但覆盖过低。** 第二轮平均只覆盖全图 0.01590%，14/121 帧有记忆。真实重叠≥100 像素且冲突>25%的候选会拒收；13 个最终选入的候选重叠不足 100 像素却冲突比例较高，按当前规则仍被允许。因此“非零记忆”不等于足够覆盖或可靠约束，不能宣称已实现完整 3D 记忆闭环。

首轮真实历史缓存的扩展有效：frame104 正后方静态 FRONT 投影覆盖从最近三个候选的 0 提高到 38.77%，正侧方从 4.00% 提高到 11.03%。但源缓存覆盖不是生成保真或最终空洞减少的指标；更高覆盖没有让本次后视生成通过。

## 复现、来源与限制

正式目录 `results/E13/val056/surround_20260928_history/`。18 个阶段全部 exit=0，总时长 133.25 分钟。242 张生成图、各类 RGB/掩码/深度/置信度数组、共同相机的 162 组 RGB/深度和 122 条来源哈希记录已审核；未改写结果数组。首次审核把 `(H,W,1)` opacity 错当成 `(H,W)`，按 `render_views.py` 修正后完整通过，失败日志保留。此前最近源帧 [0,6,15] 的试启动在生成完成前主动中止，保留在 `surround_20260928/ABORTED.json`，不是完成的质量对照。正式历史候选改为 [0,6,15,30,60,90]，仍排除留出源帧。

仓库另已登记后续只读诊断：[DECISIONS W](DECISIONS.md)。这包括旧高斯的观测支持/拉长/颜色外推，以及相同生成帧的联合深度对照；此 E13 报告不将它们的准备代码视为已完成实验。下一步应先验证局部清晰、道路结构稳定的生成目标，再做有可靠重叠的平移与联合深度约束，按有效覆盖选训练视角。减慢扫视、缩小相邻位置间距、保护已观测 warp 区域均是待验证改动；本次没有证明它们有效。暂不扩大到每帧全角度或更多场景。
