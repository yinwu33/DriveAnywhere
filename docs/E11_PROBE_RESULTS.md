# val056 生成与 3D 蒸馏分离诊断

日期：2026-09-28。对应 Phase 9 修正任务 3、DECISIONS T。分析与模型选型见 [SCENE_COMPLETION_ANALYSIS.md](SCENE_COMPLETION_ANALYSIS.md)。

## 结论

当前流程能把经过筛选的合成颜色拟合进 3D，但仍显著损失细节，未达到可用自由视角场景的质量要求。本轮没有证明生成记忆能消除模糊，也没有把问题定位到某个生成模型的能力上限。保留“生成候选 → 几何验证 → 更新持久 3D → 再生成”的路线，下一步先区分表示密度、深度和目标冲突的影响。

2026-09-28 用户进一步检查左右 90°，明确反馈 E11 与 E12 drive / sweep 均很差，完整质量失败。本轮 E11 是从 E5c 局部拟合 +60° 的模型，没有继承 E10 的全部角度；覆盖缺口不能解释 +60° 已有的失败。复查记录见 [SIDEVIEW_FAILURE_ANALYSIS.md](SIDEVIEW_FAILURE_ANALYSIS.md)。

- E10 标准 35 步生成在 +60°/+90° 蒸馏后，空洞区拉普拉斯方差比仅为 0.414/0.181，细节相关性为 0.049/0.028。+30° 方差比达到 1.157，但相关性仍仅 0.102；方差高可能来自不匹配的碎片或噪声。
- E11 两臂局部拟合都明显降低了合成目标 RGB 误差，但共同通过区的细节相关性只有 0.263/0.220。memory 的方差比稍高、相关性较低，不能据此判定质量更好。
- 直接生成帧本身也有结构碎片、重影和不稳定纹理；同相机 3D 与未监督视角仍有大块模糊、漂浮片状内容。当前证据同时指向输入/目标质量和蒸馏损失；尚不能区分深度、跨视角目标冲突与表示密度的责任。
- 真实 FRONT 的历史留出渲染指标没有明显退化；本轮没有“仅继续真实帧训练”的对照，不能把 FRONT 指标增加归因于生成记忆。

这些是历史产物的实现诊断，**不是无泄漏质量基准、隐藏区域正确率或闭环测试验收**。

## 固定协议与复现

代码提交：`e120bbcaf96090020d4661970c51f1937c2edddd`。在独立干净 worktree 上运行；生成网络未训练或微调。

```bash
.venvs/main/bin/python scripts/run_e11_probe.py \
  --out_dir results/E11/val056/probe_20260928_seeded --steps 3000
```

复现需使用新的输出目录，runner 拒绝覆盖。两臂都从 `results/E5c/val056/checkpoint_final.pth` 出发，监督生成视角 40–64（25 帧，原始帧 80–128），种子为 0，真实 FRONT loss 保持开启，`seen_w=0`。只在通过几何检查且深度有效的空洞像素处新增高斯、施加生成 loss。原配置的高斯分裂已在 15000 步停止，本次从 30000 步继续，不开启分裂。

诊断选取视角 40/44/48/52/56/60/64；保存完全相同相机的拟合，以及未参与生成/监督的 +5° 偏航和 +0.5 场景单位横移。指标在原始 1280×704 图像上计算，掩码腐蚀 1 像素排除边缘。PSNR 先按像素合并 MSE；方差比使用按像素加权的帧内方差，相关性按像素加权。

`run_status.json` 的 `completed` 与 `paired_sampling_identical` 均为 true；两臂各 3000 步的真实/生成视角采样序列完全相同。固定随机流不保证所有 CUDA 浮点运算逐位确定。

初次运行发现旧 `train_fill.py` 未固定上游真实帧采样所用的 Python `random`，在拟合完成前主动停止。日志保存在 `probe_20260928/ABORTED.json`，未纳入本报告。修正同时固定 Python、NumPy、Torch/CUDA，并保存每步采样序列；14 项合成测试通过，含上游真实帧采样回归测试。

## E11：有无跨轮记忆的局部拟合

下表在完全相同的共同验收掩码上比较，共计 70,578 个腐蚀后像素。两臂的目标 RGB 不同，因此绝对误差也受目标难度影响。

各自验收区的拟合后 PSNR 为 32.787/31.944，细节方差比 0.258/0.304，相关性 0.278/0.198；腐蚀后像素数为 120,151/230,497。完整原始空洞、各自验收区与共同区表格见 [原始报告](../results/E11/val056/probe_20260928_seeded/REPORT.md)。

![real-only 局部拟合](../results/E11/val056/probe_20260928_seeded/real_only_s8_after/052.png)

局部 25 帧的原始空洞占全图 24.70%。空洞内 real-only/memory 通过比例为 10.78%/20.32%，共同通过比例为 6.84%（这些覆盖比例未腐蚀）。多数空洞没有进入监督，不能将整体图像差异全部归因于被监督区域的拟合能力。

历史生成记忆实际平均覆盖全图仅 0.461%，最大 2.073%，25 帧中 13 帧使用了它。该配置验证了接线与有限覆盖下的表现，没有检验充分空间记忆下的上限。旧记忆来自 E10/+30°；本轮输入/掩码复用 E10/+60° 历史轮次，而拟合从 E5c 开始，因此掩码不能代表从 E5c 首轮外扩所需的全部区域。

深度实际来自 `Ruicheng/moge-2-vitl-normal`，在历史渲染边界上对齐。验收深度 5/50/95 分位数分别为 real-only 5.86/30.50/71.19，memory 4.91/28.52/71.00 个场景单位。没有独立米制验收；尺度对齐也不等于几何正确。

## 下一项验证的优先级

1. **先验证表示与拟合上限**：选固定、支持充分的单个/少量生成视角，对照当前稀疏 spawn 与有限分裂/更密初始化，固定种子和预算。单视角能保留细节、加入多视角后退化，才进一步指向目标/深度冲突；单视角也退化则先修拟合。此项仍属于任务 3，不需要微调生成网络。
2. **再完成联合几何与空间记忆**：优化跨帧深度、对应点和遮挡；按真实/已验证记忆的投影覆盖安排更近的新视角，先减少角度步长。为正式基准从 E5c 重建输入/掩码/记忆，排除旧留出源帧影响，再做相同 35 步生成对照。
3. 局部通过后才评测新 Cosmos 后端或扩大侧后视。Cosmos 输出应作为候选外观/视频，持久几何和来源继续由场景管理；新模型本身不会自动提供碰撞网格与道路语义。

“可测试资产”的后续验收还应包含道路表面、可通行区、碰撞几何、尺度和真实/生成来源。隐藏内容允许猜测时，可考虑固定网格/资产作为场景假设，外观再由生成与重建补充；这是待验证备选，本轮没有实施仿真集成。
